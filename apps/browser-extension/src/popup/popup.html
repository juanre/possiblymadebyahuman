PMBAH · Writing records

Choose an editor before starting. The record contains editing measurements, not your words.

Start in an editor

Right-click an empty editor and choose “Start writing record”. Or focus the editor, then use the button below. Opening this panel does not start anything.

Keyboard alternative: focus the editor, then press Alt+Shift+W to start its writing record and open this panel. You can change the shortcut in Chrome’s extension settings.

Checkpoints send edit measurements while a chosen draft is active. Finishing stops capture. A saved public record cannot be deleted here. Privacy details
